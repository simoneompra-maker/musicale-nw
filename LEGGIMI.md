# Musicale NW – Sile Walking

PWA per la serata musicale di Nordic Walking: ritmo in BPM, conteggio in 4 o 8 tempi, libreria di esercizi, scalette salvabili, basi ritmiche generate e brani MP3 propri.

## Pubblicazione su GitHub Pages
1. Su GitHub (account simoneompra-maker) crea un repository nuovo, per esempio `musicale-nw`, pubblico.
2. Carica i file di questa cartella (Add file → Upload files): index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.
3. Settings → Pages → Branch: `main`, cartella `/ (root)` → Save.
4. Dopo un minuto l'app è su `https://simoneompra-maker.github.io/musicale-nw/`.
5. Dal telefono apri l'indirizzo con Chrome → menu ⋮ → "Aggiungi a schermata Home".

## Note
- Brani, scalette ed esercizi personali restano salvati sul telefono che li usa.
- Per passare una scaletta a un altro istruttore: Scalette → Modifica → Esporta, poi lui fa Importa.
- Usa in pubblico solo musica che hai il diritto di diffondere.
